## About Me

I build low-level Android utilities, custom recoveries, portable Linux environments, and experimental OS ports. Whether it's flashing Samsung firmware over USB-OTG without a PC using native C++ JNI bridges, experimenting with XNU kernel bringup on ARM hardware (`UniXNU-pipa`), porting custom recoveries, or packaging cross-platform QEMU workspaces — I pick whatever tool fits the problem best.

## 🚀 Featured Projects

**[Freyja](https://github.com/EsaiJJ/Freyja)** — Open-source Android-native Samsung flashing utility built in Kotlin & C++ (JNI) with Odin4 and Heimdall engines to flash firmware slots (`BL`, `AP`, `CP`, `CSC`), `recovery.img`, and `vbmeta.img` over USB-OTG without needing a PC.
![Stars](https://img.shields.io/github/stars/EsaiJJ/Freyja?style=flat-square&color=f75c7e) ![Language](https://img.shields.io/github/languages/top/EsaiJJ/Freyja?style=flat-square&color=f75c7e)

**[UniXNU-pipa](https://github.com/EsaiJJ/UniXNU-pipa)** — Experimental UniXNU / XNU kernel bringup and boot-image port targeting the Xiaomi Pad 6 (`pipa` / SM8250) ARM64 hardware.
![Stars](https://img.shields.io/github/stars/EsaiJJ/UniXNU-pipa?style=flat-square&color=f75c7e) ![Language](https://img.shields.io/github/languages/top/EsaiJJ/UniXNU-pipa?style=flat-square&color=f75c7e)

**[MyUSBticOS](https://github.com/EsaiJJ/MyUSBticOS)** — Cross-platform portable workspace and QEMU virtual machine launcher (`.deb`, `.exe`, and `.apk`) that boots a preconfigured Debian 12 system image with persistent shared storage straight from a USB drive.
![Stars](https://img.shields.io/github/stars/EsaiJJ/MyUSBticOS?style=flat-square&color=f75c7e) ![Language](https://img.shields.io/github/languages/top/EsaiJJ/MyUSBticOS?style=flat-square&color=f75c7e)

**[MysticRecovery](https://github.com/EsaiJJ/mystic-recovery-sm-t510)** — Custom source-built fork of PitchBlack Recovery Project (`android-12.1`) tailored for the Samsung Galaxy Tab A 10.1 2019 (`SM-T510` / `gta3xlwifi`) with automated build and branding workflows.
![Stars](https://img.shields.io/github/stars/EsaiJJ/mystic-recovery-sm-t510?style=flat-square&color=f75c7e) ![Language](https://img.shields.io/github/languages/top/EsaiJJ/mystic-recovery-sm-t510?style=flat-square&color=f75c7e)
